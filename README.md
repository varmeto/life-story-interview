# 深度访谈与人生记录 v1

一个可分享的通用 Agent Skill。通过温和的一问一答，记录想聊的话题、想法或个人经历，也可以逐步整理人生编年史。

它改编自 MIT 许可的 `oral-history-kit`，并参考 `build-my-memory-file`。完整来源及修改说明见 [NOTICE.md](NOTICE.md)。

## 开始使用

将整个 `life-story-interview` 目录交给支持 `SKILL.md` 的 Agent，按该工具的方式加载或放进它的技能目录。保留 `references`、`examples` 和许可证文件。

可以这样开始：

> 使用 life-story-interview。我想聊聊第一次组织活动的经历，一次问一个问题，先让我慢慢讲。

> 帮我记录人生经历。我想从大学那几年开始，不一定按顺序讲。

> 继续这份检查点里的访谈，今天先聊上次我主动提到的那个项目。

不支持安装 Skill 的聊天工具，可以把 [SKILL.md](SKILL.md) 作为对话指令，并附上 [归档规则](references/record-keeping.md) 和 [模板](references/templates.md)。是否能自动保存文件、读取附件或续聊，取决于宿主实际能力，不保证每个平台都支持。

## 聊起来是什么样

- 一次最多一个主要问题；可以不提新问题，让你继续讲。
- 讲完一个事件或话题，再简短核对信息，不每句话都打断。
- 可以说“跳过”“换一个”“先暂停”“这段不要记录”。
- 不打分、不讽刺、不诊断、不擅自解释动机，也不要求必须聊出创伤或重大转折。
- 不确定的日期保留为不确定；只确认一部分，就只更新那部分。

## 会得到什么

在你授权保存、宿主也具备文件能力后，记录放在工作区独立目录：

| 文件 | 内容 |
| --- | --- |
| `transcript.md` | 原始问题、完整回答、主动补充及校正依据 |
| `notes.md` | 按主题或时间整理，区分本人确认、待确认和不确定内容 |
| `checkpoint.md` | 停在哪里、哪些讲过或跳过，方便下次接着聊 |

没有保存授权或文件能力时，会在聊天中给出可复制文本，并说明未写入文件。续聊时提供先前记录或检查点；它不会凭空记得跨会话内容。

“本人确认”表示记录准确表达了你的自述，不代表第三方事实已经核实。Skill 不自动上传记录、写入全局记忆、发布到 GitHub 或把访谈设为系统指令。
